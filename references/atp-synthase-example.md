# 6CP6：ATP 合酶实例与迁移边界

这是技能来源实例，不是每次都要复制的页面或配色。

## 结构与机制分开

- 条目：[6CP6](https://www.rcsb.org/structure/6CP6)，酵母线粒体 ATP 合酶；[原始论文](https://doi.org/10.1126/science.aas9699)说明实验将转子限制在一个构象。不能称由该文件还原了真实旋转轨迹。
- 作者链 K–T：10 个 c 亚基；A–C / D–F：三组 alpha / beta；G/H/I：中央转子组；X：a 亚基；其余支撑组需依据实体注释确认。mmCIF label 链名和旧 PDB 作者链名不同。
- c₁₀ 是这个酵母体系的事实，不是所有 ATP 合酶的通用数量。理想耦合一圈的 10 H⁺ / 3 ATP 不包含其他线粒体运输成本。
- 基质侧的 F1 头部固定，中央轴与 c 环转动。a 亚基有错开的入口/出口半通道；示踪粒子不能穿过 c 环中央当成普通直通孔。
- 只有静态数据时，采用放慢的刚体转动与小幅、明确标注的催化开合示意；不要在物理时间/电压/能量缺乏依据时给出伪精确读数。

## 可复用的控制关系

整体 → 转子近看 → 催化头近看；控制梯度、播放/暂停、120° 单步。三个催化位置分别结合 ADP+Pi、形成 ATP、释放 ATP。动画和计数从同一纯函数快照计算：3 次手动 120° 步进对应一圈、3 ATP，理想 c₁₀ 环对应 10 H⁺。

将“暂停”“示意驱动力归零”和“页面隐藏”分别处理。前两个停止工作原理推进，手动拖动相机仍可用；离屏/后台恢复不补跳时间。这个正向示意没有模拟 ATP 水解驱动的反转，说明中注明即可。

## 示例模块划分（可选）

WonderLab X 实例按以下职责组织模块；新项目可沿用自己的结构。`anatomy-spec.mjs` 保存事实/分组/纯函数，`scene.mjs` 保存几何和镜头，`runtime.mjs` 保存交互。原例资产是另一套编码，不可直接与本技能构建器的解码器混用。

资料：[PDB-101 ATP Synthase](https://pdb101.rcsb.org/motm/72) 适合教学叙事，但其中较早的拼合模型有不同转子亚基数；不能用那段数量覆盖 6CP6 的实际 c₁₀。

迁移验证发现：该 mmCIF 按聚合物身份读取可得到 5,128 个 Cα；旧示例只读取旧 PDB 的 ATOM 得到 5,118 个。不要把旧示例计数当作所有格式的硬编码验收值，需检查修饰残基与 HETATM 记录。
