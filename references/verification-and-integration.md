# 验证与项目接入

## 采用与交付规模相称的检查

纯模型检查来源、链/装配体、单位、坐标与网格，附必要的临时预览即可。网页再验证浏览器行为，不为简单静态模型增加机制模拟或完整产品后台。

与原条目截图对照整体方向、链数量、对称性、配体位置及重要接触。若还原的是生物装配体，尤其检查是否少了一半、把晶体接触当成生物相互作用，或重复应用了装配变换。

## 数值与浏览器

- 网格索引均小于顶点数，法线有限且近似单位长度；量化坐标不溢出，大坐标下局部量化能正确还原。不要通过 clamp 坐标偷偷“修复”溢出。
- 检查近看、剖切、旋转、选择和返回。每个不同的连接/通道/开口在约整体视图 4 倍近看并截图；真实缺失区域与程序裂缝分别说明。
- 检查桌面与窄屏；存在双语时实际验证两种语言，别把跳回中文的页面当英文通过。WonderLab X 的浏览器语言路由需要测试链接带 `?lang=en` 并断言根节点语言。
- 测试真正的鼠标、滚轮、触摸/键盘事件；数值 setter 只能证明状态函数，不证明点击控件可达。CDP 测试滚动时用 `behavior:'instant'`，避免全局 smooth scroll 使点击打中移动中的邻近元素；考虑固定页眉遮挡。
- WebGL 截图用实际合成画面。`preserveDrawingBuffer:false` 时，异步 `canvas.toDataURL()` 可能得到空白，不能据此判断暂停画面稳定。
- `ready` 标记应在首帧成功绘制后设置，避免资源加载完成但画面未出现就判定成功。读取实际异常和资源响应。

## 几何、标尺与性能

- 分子坐标与相机适配分开，复用几何和材质；每帧只更新变换/morph/状态。不要逐帧重做等值面。
- 可隐藏的脂质/背景实例按状态变化更新，而非每帧循环重写矩阵。把实例缩放设为 0 后，再分解矩阵可能得到无效旋转；恢复时从原始位置/姿态重建。
- 视角切换应能被拖动、滚轮和 +/- 键打断。缩放最小距离需避免相机钻进蛋白。切开前侧膜时，开口应与初始观察方向一致，转动后仍保持合理物理遮挡。
- 标尺用观察中心深度处的相机水平向量投影；近看时改用更小单位，不用 CSS `max-width` 截短标尺却保留原数字。标签锚点属于实际部件，随旋转/morph 更新；离屏或隐藏时不展示悬空标签。
- 先预热相关视图，再比较重复切换后的 geometry/texture 趋势；首次显示的资源增长不自动等于泄漏。记录 draw calls、三角形和真实运行异常；不把代码检查当成帧率实测。

## WonderLab X 接入（仅在该项目使用）

站内页沿用共享 shell：`src/experiments/<slug>/build.mjs` 输出 `{body,css,script}`，组件 CSS 作用域限定根节点，双语元数据在 `src/experiments/registry.mjs`。资源放 `assets/models/`，封面用真实预览截图；`experiments/`、`assets/experiments/` 等是构建产物，不直接编辑。

运行现有 `npm run build`、`check:experiments`、`check:seo`、`check:language`；读实际 package scripts，不在其他项目照抄命令。通过 HTTP 启动后验证本地页面与资源。该项目 `scripts/serve.mjs` 使用 `PORT=4199`，不会读取 `--port`。如服务已停止，重启并验证监听与浏览器；不要把旧 QA 报告当成当前服务存活证明。

用户要求“做出来看看”交付本地预览；只有请求发布时才使用项目部署路径。不要改变其他目录条目或顺带发布同工作区里其他未审核实验。
